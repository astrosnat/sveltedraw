# SvelteDraw
Attempting to port Excalidraw to Svelte.

## But why, though?
Because Excalidraw is a useful tool for artists, but React has lots of performance issues.

## How to use SvelteDraw

### Prerequisites
You will need [Docker Desktop](https://www.docker.com/products/docker-desktop/) and Windows or Linux. macOS has not been tested yet, **use at your own risk**.

### Using SvelteDraw locally
1. In your terminal, type in `git clone https://github.com/astrosnat/sveltedraw`.
2. Navigate to the `sveltedraw` file on your computer.
3. Run `docker build .`
4. In Docker Desktop, start the container.
5. Navigate to `localhost:5173`
6. Have fun drawing!
