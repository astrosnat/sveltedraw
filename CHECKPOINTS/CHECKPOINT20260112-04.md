Building an Excalidraw clone is a fantastic project for Svelte because Svelte’s reactivity model (especially Svelte 5’s Runes) maps perfectly to a canvas-based application's state.

Here is the architectural roadmap to building this using **Svelte 5** and **Rough.js**.

### 1. The Core Architecture
Excalidraw is not a typical DOM-based app. It uses an **Immediate Mode** rendering strategy. This means you have one single `<canvas>` element that is completely cleared and redrawn every time something changes (or every frame).

**Your Stack:**
*   **Svelte 5**: For managing the state of the "Scene" (all your shapes).
*   **Rough.js**: A tiny library (~9kb) that draws the "hand-drawn" primitives on the canvas.
*   **HTML5 Canvas**: The rendering engine.

---

### 2. State Management (The "Scene")
In Svelte 5, you can use a global `$state` object to represent your scene. You don't need complex stores; a simple Rune-based class works best.

```javascript
// scene.svelte.js
class Scene {
  elements = $state([]); // Array of all shapes
  selection = $state([]); // IDs of selected shapes
  camera = $state({ x: 0, y: 0, zoom: 1 });
  
  // Current tool state
  activeTool = $state('selection'); // 'rectangle', 'line', etc.
  
  addElement(element) {
    this.elements.push(element);
  }
}

export const scene = new Scene();
```

### 3. The Render Loop
You cannot rely on Svelte to render the canvas updates via the template. Instead, you need a "Game Loop" using `requestAnimationFrame`.

Create a `Canvas.svelte` component:

```svelte
<script>
  import { onMount } from 'svelte';
  import rough from 'roughjs';
  import { scene } from './scene.svelte.js';

  let canvas;
  let ctx;
  let roughCanvas;

  onMount(() => {
    ctx = canvas.getContext('2d');
    roughCanvas = rough.canvas(canvas);

    let frameId;

    const render = () => {
      // 1. Clear Screen
      ctx.clearRect(0, 0, canvas.width, canvas.height);

      // 2. Apply Camera Transform (Pan/Zoom)
      ctx.save();
      ctx.translate(scene.camera.x, scene.camera.y);
      ctx.scale(scene.camera.zoom, scene.camera.zoom);

      // 3. Draw all elements
      scene.elements.forEach(el => {
        if (el.type === 'rectangle') {
          roughCanvas.rectangle(el.x, el.y, el.width, el.height, {
            seed: el.seed // Important! Keep seed constant so it doesn't "jitter" every frame
          });
        }
        // ... handle other shapes
      });

      ctx.restore();
      frameId = requestAnimationFrame(render);
    };

    render();

    return () => cancelAnimationFrame(frameId);
  });
</script>

<canvas bind:this={canvas} width={window.innerWidth} height={window.innerHeight} />
```

### 4. Handling Input (Drawing)
You need to map DOM events (`mousedown`, `mousemove`, `mouseup`) to your shape data.

*   **MouseDown**: Record the starting `(x, y)` and create a new placeholder shape in your `scene.elements` array.
*   **MouseMove**: Update the dimensions (width/height) of that active shape. Because `scene.elements` is a `$state` proxy, Svelte will update the data, and your `render` loop reads it on the next frame.
*   **MouseUp**: Finalize the shape (maybe simplify the path if it's a free-draw line).

**Crucial math note**: You must convert "Screen Coordinates" (mouse event) to "World Coordinates" (canvas logic) by reversing the camera transform:
```javascript
const worldX = (event.clientX - scene.camera.x) / scene.camera.zoom;
const worldY = (event.clientY - scene.camera.y) / scene.camera.zoom;
```

### 5. Hit Testing (Selection)
This is the hardest part. Since you are drawing pixels, the browser doesn't know what a "shape" is. You have to calculate it mathematically.

*   **Rectangles**: Check if the point is inside the bounding box.
*   **Lines**: Use the "Point to Line Segment Distance" formula. If the distance is less than a threshold (e.g., 5px), consider it a click.

*Helper function for line detection:*
```javascript
function distanceToLine(x, y, x1, y1, x2, y2) {
  const A = x - x1;
  const B = y - y1;
  const C = x2 - x1;
  const D = y2 - y1;
  const dot = A * C + B * D;
  const len_sq = C * C + D * D;
  let param = -1;
  if (len_sq !== 0) param = dot / len_sq;
  let xx, yy;
  if (param < 0) {
    xx = x1; yy = y1;
  } else if (param > 1) {
    xx = x2; yy = y2;
  } else {
    xx = x1 + param * C;
    yy = y1 + param * D;
  }
  const dx = x - xx;
  const dy = y - yy;
  return Math.sqrt(dx * dx + dy * dy);
}
```

### 6. The "Hand-Drawn" Feel
`Rough.js` is doing the heavy lifting, but to make it feel like Excalidraw, you need to:
1.  **Store a Seed**: Generate a random seed (`Math.floor(Math.random() * 2**31)`) when you create a shape and save it. Pass this seed to `roughCanvas` every time you draw. If you don't, the "roughness" will randomize every frame, making the lines shake.
2.  **Font**: Excalidraw uses a custom font named "Virgil". You'll need to load a similar handwritten web font for text elements.

### 7. Infinite Canvas Logic
To achieve the infinite canvas, you just manipulate `scene.camera`.
*   **Panning**: On `wheel` (or space+drag), add `event.deltaX/Y` to `scene.camera.x/y`.
*   **Zooming**: This is tricky. You want to zoom *towards the mouse pointer*.
    ```javascript
    const zoomSensitivity = 0.1;
    const newZoom = scene.camera.zoom - event.deltaY * zoomSensitivity;
    
    // Math to keep the point under the mouse stable
    const mouseWorldXBefore = (mouse.x - scene.camera.x) / scene.camera.zoom;
    scene.camera.x -= (mouseWorldXBefore * newZoom - mouseWorldXBefore * scene.camera.zoom);
    scene.camera.zoom = newZoom;
    ```

### Why Svelte for this?
In React, getting the high-performance render loop often requires "breaking out" of React (using `useRef` heavily and avoiding state updates for mouse movements). In Svelte, fine-grained reactivity means you can update the `width` of a rectangle 60 times a second without triggering a component re-render overhead—your loop just reads the updated values naturally.
