I've created a starter example for you! This is actually built in React since we're in the Claude interface, but the structure directly translates to Svelte - here's how you'd convert it:

## Key Svelte Translations:

**1. State Management:**
- `useState` → Svelte variables: `let elements = []`
- `useRef` → `bind:this={canvas}` in the template
- `useEffect` → `$:` reactive statements

**2. Svelte Version Structure:**
```svelte
<script>
  let canvas;
  let elements = [];
  let selectedTool = 'rectangle';
  let isDrawing = false;
  let currentElement = null;

  // Reactive re-render when state changes
  $: if (canvas) render();
  $: elements, currentElement, render();

  // All the same functions (screenToCanvas, createElement, etc.)
</script>

<div class="container">
  <div class="toolbar">
    <button on:click={() => selectedTool = 'rectangle'}>
      Rectangle
    </button>
    <!-- etc -->
  </div>
  
  <canvas
    bind:this={canvas}
    on:mousedown={handleMouseDown}
    on:mousemove={handleMouseMove}
    on:mouseup={handleMouseUp}
  />
</div>

<style>
  /* CSS goes here */
</style>
```
