#### **C. Undo/Redo System**
```javascript
// history.js
export class HistoryManager {
  constructor() {
    this.stack = [];
    this.currentIndex = -1;
  }
  
  push(state) {
    // Truncate future states if we're not at the end
    this.stack = this.stack.slice(0, this.currentIndex + 1);
    this.stack.push(JSON.parse(JSON.stringify(state)));
    this.currentIndex++;
  }
  
  undo() {
    if (this.currentIndex > 0) {
      this.currentIndex--;
      return this.stack[this.currentIndex];
    }
  }
  
  redo() {
    if (this.currentIndex < this.stack.length - 1) {
      this.currentIndex++;
      return this.stack[this.currentIndex];
    }
  }
}
```

### 6. **Performance Optimizations**

```javascript
// Only re-render changed elements
function shouldRenderElement(element, prevElement) {
  return (
    element.x !== prevElement.x ||
    element.y !== prevElement.y ||
    element.width !== prevElement.width ||
    element.height !== prevElement.height ||
    element.isSelected !== prevElement.isSelected
  );
}
```

### 9. **Key Differences from React Implementation**

- **Reactivity**: Svelte's reactivity is compile-time vs React's runtime
- **State updates**: Direct assignment triggers updates in Svelte
- **No virtual DOM**: Direct DOM updates can be faster for canvas operations
- **Simpler components**: Less boilerplate than React components
